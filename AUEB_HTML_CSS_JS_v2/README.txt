WikiShop Web App - Εφαρμογή ηλεκτρονικού καταστήματος που συνδέεται με το WikiShop API.

Τεχνολογίες:
HTML, CSS, JavaScript
Handlebars.js, Fetch API
Node.js, Express

Λειτουργίες:
Προβολή κατηγοριών & προϊόντων
Φιλτράρισμα ανά υποκατηγορία
Login χρήστη & προσθήκη σε καλάθι
Προβολή περιεχομένου καλαθιού
